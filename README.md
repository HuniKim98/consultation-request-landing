# SK Escape Lime - Personal Consulting Landing Page

더에스케이프라임 개인 상담신청 랜딩페이지입니다.

## 배포

이 프로젝트는 Vercel에서 호스팅됩니다.

### Vercel에서 배포하기

1. [Vercel](https://vercel.com)에서 계정을 만드세요
2. GitHub 저장소를 연결하세요
3. Vercel이 자동으로 배포합니다

## 로컬에서 실행하기

```bash
npm run dev
```

또는

```bash
python -m http.server 3000
```

## 개발

로컬 서버는 `http://localhost:3000`에서 실행됩니다.
